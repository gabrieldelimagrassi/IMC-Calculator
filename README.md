# IMC CALCULATOR

**Desafio de Kotlin e Android**

Este repositório é um **Desafio** do curso da Escola Nova Era Tech para colocar em prática os aprendizados da Trilha de Android que é o 10D Challange.

## 📱 Sobre o aplicativo

O aplicativo tem como funcionalidade calcular e gerar o resultado do IMC do usuário.

## Requisitos para o aplicativo

- Splash Screen e navegação para o formulário
- Tela com campos de peso (kg) e altura (m)
- Botão para calcular o IMC
- Tela de resultado com o valor do IMC (duas casas decimais)
- Classificação: abaixo do peso, peso normal, sobrepeso, obesidade grau I, II e III
- Fórmula IMC = peso / (altura × altura)
- Passar os dados entre telas com Intent
- Validar campos vazios e valores inválidos (peso ou altura ≤ 0)
- Layout com ConstraintLayout e TextInputLayout
- Sem persistência e sem API


Toda a lógica é desenvolvida principalmente em Kotlin, utilizando os conceitos apresentados durante as aulas e evoluindo gradualmente conforme o conteúdo do curso.

## 🧩 Tecnologias e conceitos utilizados

Este projeto utiliza apenas fundamentos do Android tradicional, ideal para iniciantes:

- Kotlin
- Activities
- UI com XML
  - TextView
  - EditText
  - Button
- Validação de campos
- Navegação entre telas com Intent
- Passagem de dados entre telas com Bundle
- Toolbar
- Organização básica de layouts e telas
